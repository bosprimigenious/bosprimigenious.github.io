# Markdown 零基础教学笔记

Markdown 是一种轻量级的标记语言，常用于写作文档、博客、技术文档等。其语法简洁，易于学习，广泛应用于 GitHub、博客、论坛等平台。

## 一、基本语法

### 1. 标题
Markdown 使用 `#` 来表示标题。`#` 的数量决定了标题的级别。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```
